# Три кадра за проход — как снять скриншоты

Скриншоты в этой папке сняты локально, без боевой таблицы и без ключа Gemini.

1. Поднять демо-сервер (он подменяет `/exec` и «вердикты» модели):

   ```
   node tools/demo-server.mjs
   ```

2. Снять экраны (нужен установленный Chrome; по умолчанию
   `C:\Program Files\Google\Chrome\Application\chrome.exe`, можно задать
   `CHROME_PATH`):

   ```
   node tools/screenshot-photo-run.mjs
   ```

Скрипт поднимает headless Chrome в окне 375×812, входит как «Анна»,
проходит поток «этаж → три кадра → отправка», снимает сводку, историю,
строку «зона не определена» с выбором зоны и результат перепроверки.
Отдельно снимается блок «Стоп-лист» на экране съёмки — со снимком в нём.
Файлы кладутся сюда же: `01…06-*.png`.

Демо-сервер отдаёт заранее заданные ответы (зоны по этажу, уровни
ok/warn/crit, при `?photoundef=1` второй кадр — «зона не определена»,
стоп-лист — «распознано 5, по нулевому остатку 1, кухня 3»).
Это только для экранов: качество и время реальной модели измерялись
отдельно на настоящих фото, см. `ОТЧЁТ.md`.

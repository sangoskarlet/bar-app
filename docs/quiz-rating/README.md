# Рейтинг викторины — проверка

Боевой бэкенд развёрнут **версией 15** того же развёртывания (`/exec` не менялся).
Приложение проверено на локальном сервере с боевым `config.js`.

| Файл | Что видно |
|---|---|
| `01-start-record.png` | старт викторины: «Лучший результат: 10 из 10 · попыток: 5» из локального кэша |
| `02-result-record.png` | результат попытки 10/10 и «Лучший результат… · попыток: 4», «Результат сохранён» |
| `03-offline-queued.png` | результат без сети: «сохранён на телефоне — уйдёт, когда появится сеть», попыток уже 5 |
| `04-sheet-attempts.png` | лист «Викторина»: сырые попытки, `attempt_id` в первой колонке |
| `05-sheet-rating.png` | «Рейтинг»: дуэльные A–F и викторинные G–J; попытки, лучший, средний, последняя |

Схема «Рейтинга» целиком (A–J):

`сотрудник | рейтинг | побед | поражений | матчей | последний_матч | викторина_попыток | викторина_лучший | викторина_средний | викторина_последняя`

Схема «Викторины»:

`attempt_id | дата | сотрудник | верно | всего | секунд | версия_банка`

Тестовые данные: в «Викторине» остались попытки тестового сотрудника и одна попытка
сотрудника без дуэльной строки (проверка автосоздания строки в «Рейтинге»).
Они **не удалялись** — решение за владельцем.

# Дуэль v1 — проверка

Боевой бэкенд развёрнут **версией 14** того же развёртывания (`/exec` не менялся),
приложение проверено на локальном статическом сервере с **боевым** `config.js`:
два разных origin — две независимые сессии IndexedDB, поэтому в одном Chrome
играли два сотрудника одновременно.

Тестовые строки в «Дуэлях» помечены кодом, начинающимся с `TEST`; они **не удалялись** —

матчах (Elo пересчитан по-настоящему).

## Что проверено на боевом `/exec`

Сценарий из двух клиентов (создание → вход по коду → полный матч до 0 HP → запись
результата → Elo) и негативные случаи:

* неверный код комнаты и не-сотрудник — отказ;
* третий игрок в занятую комнату — отказ;
* двойной ответ в одном раунде и попытка изменить ответ — отказ;
* ответ после дедлайна 30 с — отказ, раунд закрывается без урона;
* второй правильный ответ в окне 7 с — блок, 0 урона;
* второй правильный ответ позже 7 с — урон всё равно проходит первому;
* оба неправильных — 0 урона;
* оба правильных одновременно — порядок определяет сервер (по времени получения), блок;
* отмена ожидания и повторный вход создателя;
* deep-link `?duel=КОД` при старте приложения: код подхватывается, комната открывается;
* перезагрузка во время ожидания и во время боя — экран восстанавливается по `duelState`;
* ожидание 2 минуты истекло — комната закрыта, состояние отвечает `expired`;
* 15 раундов без ответов — ничья 10:10, рейтинг сдвинулся на половину очка;
* посторонний сотрудник не видит состояние чужого матча;
* в состоянии текущего раунда нет `correct`/`пояснение` — правильный ответ появляется
  только в `lastRound` после закрытия раунда;
* после матча Elo пересчитан (K=32, старт 1000), сумма рейтингов пары сходится с точностью
  до округления; листы «Дуэли» и «Рейтинг» заполнены.

## Что осталось за владельцем

* Удалить или оставить тестовые строки `TESTJV`, `TEST-L7A6AT` и `TESTDN` в «Дуэлях» — по желанию.
* При желании обнулить рейтинг участников тестовых матчей в листе «Рейтинг».
* Проверить на двух реальных телефонах в бою (проверка шла в двух вкладках Chrome
  на одном компьютере; серверная логика от этого не зависит, но вёрстка на телефоне
  и реальная задержка сети не проверялись).
* Осознанный остаток v1: `?action=questions` (существующее действие викторины)
  по-прежнему отдаёт банк вопросов вместе с правильными ответами — это нужно
  викторине для офлайна. Через консоль браузера сотрудник теоретически может
  подсмотреть ответы. Состояние дуэли их не отдаёт; полноценная защита —
  отдельные токены и зачётный пул из волны 5 плана, вне рамок v1.

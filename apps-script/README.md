## Викторина: как выложить

Банк вопросов живёт в `content/вопросы.tsv` (60 вопросов, 10 колонок). Из него
собирается `Вопросы.gs`:

```
node tools/gen-questions.mjs
```

Дальше (нужен **включённый Apps Script API** —
<https://script.google.com/home/usersettings>, тумблер «API скрипта приложений Google Apps»):

```
cd apps-script
npx @google/clasp login          # откроет браузер, нажать «Разрешить»
npx @google/clasp push           # заливает Код.gs, Вопросы.gs, appsscript.json
npx @google/clasp deploy -i AKfycbzRXm4P2dC_xEmSrw4RjAXWk6J-Hav54iHrXK8xddGH9o5NcsdchIKkaZArwGqvAJN7-w
```

`deploy -i` обновляет **существующее** развёртывание — адрес в `config.js` не меняется.
Новое развёртывание создавать не нужно.

Затем один раз вручную запустить `setupQuiz()` (редактор Apps Script → выбрать функцию
→ «Выполнить»): создаются листы «Вопросы» и «Обжалования», в «Вопросы» заливаются
60 вопросов со статусом «в игре». Повторный запуск ничего не дублирует.

Проверка: `<URL>/exec?action=questions` должен вернуть `ok:true`, 60 вопросов,
`version` и поля `пояснение`/`источник` у каждого.

Жалоба из приложения (`POST {action:'dispute'}`) пишет строку в «Обжалования»
и ставит вопросу статус «карантин» — после этого `?action=questions` его не отдаёт.

Полный разбор логики, схемы данных, ошибок и рисков — в [`РАЗБОР.md`](РАЗБОР.md).
